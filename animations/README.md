# Blazing Flames Studio — VRMA motion files

Place the following two **binary** files directly in this folder, preserving names and case:

- `Male_WaveDance.vrma` (wave dance; approximately 15.97 seconds)
- `Male_Breakdance.vrma` (breakdance; approximately 2.10 seconds)

These are animation-only files; DO NOT upload original VRM characters to GitHub. The VRM models remain in private Cloudflare R2.

For a GitHub web upload: open this `animations/` directory, select **Add file → Upload files**, choose these two `.vrma` files from your PC, then **Commit changes** to the main branch. The viewer will request them at `./animations/Male_WaveDance.vrma` and `./animations/Male_Breakdance.vrma`.

The website supplies VRMA playback controls. The binary motion files are uploaded separately.

Before publishing, verify the original motion source's license permits redistributing the VRMA files on a public website.
