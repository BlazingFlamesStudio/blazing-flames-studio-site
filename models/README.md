# 3D VTuber model assets

Upload the optimized `*.vrm.gz` files from the Blazing Flames Studio asset packs **into this folder**.

For example:
- `models/aino.vrm.gz`
- `models/castorice.vrm.gz`
- `models/noelle.vrm.gz`

The 3D viewer automatically loads these files when their catalogue entries are selected. All model paths are registered in `../asset-manifest.json`.

Do not upload the unoptimized originals; each optimized archive already contains files in the correct `models/` folder structure.

Note: Public VRM assets are accessible to visitors, even without a visible download button.
