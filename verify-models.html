How to read the results:

“Accessible” means R2 returned a successful HTTP response with browser CORS permissions. A 404 means the file is missing at the exact expected path; a CORS/network error means this browser cannot read it, even if it exists. Model rendering and texture quality are not tested here.

If all files show CORS errors, enable GET and HEAD for origin https://blazingflamesstudio.github.io in your R2 bucket's CORS policy. If all say HTTP 404, check the exact object keys in R2: this site expects names like models/aino.vrm, not files at the bucket root or using their original upload filenames.
